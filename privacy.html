Privacy Policy

Last updated: September 26, 2026

Validation Tool ("the app") is a personal application operated by its owner for their own use.

Google user data the app accesses

With the owner's authorization via Google OAuth (scope https://www.googleapis.com/auth/adwords), the app accesses the owner's own Google Ads account to create, update, pause and report on Search campaigns (campaign settings, budgets, keywords, ads, and performance metrics such as impressions, clicks and cost).

How the data is used

The data is used only to run and measure the owner's demand tests and enforce spend caps. It is not used for advertising profiling, not sold, and not shared with any third party.

Storage and retention

OAuth tokens and campaign summaries are stored on a private server controlled by the owner. They are kept only as long as needed for active tests and can be revoked at any time at myaccount.google.com/permissions.

Limited Use

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
